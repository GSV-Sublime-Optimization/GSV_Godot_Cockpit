## Shared competition acceptance / how to establish a winner

All contestants should receive the same bounded source fixture and a second physically observed source snapshot. Score 0..5 in each dimension with receipts, rather than awarding points for impressive prose:

1. VISUAL SEMANTICS: rig, project, mission, PR, service, tool, suggestion are distinguishable without a legend; independent user names a state from 3D rendering alone.
2. REACTIVITY: keyboard/mouse/touch select *any* observed node; camera focus and filtering are reliable at 1280x720 and 1600x900; known Xanadu-selection bug cannot recur.
3. SOURCE HONESTY: blank, stale, corrupt, unobserved, future-dated and denied data fail closed without fake live actors/heartbeats/PR readiness.
4. REAL ACTION: authenticated owner-backed end-to-end R0 diagnosis, then separately approved R2 edit, exact-head test, receipt, artifact and playable game handoff.
5. REVIEW GATE: choose highest-yield PR, evidence head, owner/provenance/checks, independent reviewer, sequence dependencies, no unauthorized branch mutation.
6. INTELLIGENCE: next-step suggestions cite an observed blocker; export bounded agent handoff; show recurrence and outcomes without conflating a proposal with a fix.
7. RESOURCE EFFICIENCY: measured idle/active CPU, VRAM, GPU frame time, network and tool-call budget on MSI and i3; non-visible scene must not spin indefinitely.
8. CONNECTOR QUALITY: OmniSynapse, GitNexus, Obsidian, PU queue, GSV, Studio and plugin statuses are typed and source-admitted. A local path does NOT imply a live connector.
9. ACCESSIBILITY: full keyboard path, high contrast, readable text, screen scaling, reduced motion, and an accessible non-3D fallback.
10. SAFETY/PORTABILITY: no fabricated execution, secrets in scene output, uncontrolled privileged tools, Windows-only silent breakage or destructive checkout resets.

Required final round: ask the same agent to diagnose a real failing game test, choose an actual existing repository, create the owner-governed mission, observe result, find its PR, cite exact HEAD, review without stale approvals, and hand off a runnable artifact. The interface must reveal the journey spatially, not simply display metrics. No current contestant has independently proven this entire round here.
